    Rec · 01The problem

    An AI agent signs whatever it decides to sign. One unlimited approval empties the wallet. SafeHands is the check that runs before the signature.

    Language models are probabilistic. Money is not. The gap between "usually right" and "safe with your funds" is exactly where an agent goes wrong: a spoofed router, a lookalike recipient, an approval with no ceiling. A firewall closes that gap with a rule, not a guess.

    Rec · 02How it works
    01 · Propose

    The agent plans

    Your model finds the opportunity and builds the transaction. It holds the wallet.

    02 · Inspect

    The engine reads

    SafeHands checks the intent, then the exact calldata, against the registry and live chain state.

    03 · Stamp

    A verdict, not a vibe

    ALLOW, WARN, or BLOCK with named reasons. Deterministic: same input, same answer.

    04 · Sign

    Your wallet acts

    Only what cleared reaches a signature. SafeHands never touches a key.

    A firewall that cannot move funds is one nobody has to trust with funds. That is the whole design: safety you can put in front of every agent, because it can never become the thing it guards against.

    Rec · 03Why trust it
    a

    Deterministic

    Every verdict is computed by code and traces to a named check. Run it twice, get the same answer. No model is asked to judge safety.

    b

    Registry-backed trust

    Recognition comes only from first-party, on-chain registry evidence. An unverified address is never quietly treated as "known."

    c

    Fail-closed

    Missing evidence is reported as UNKNOWN and escalates the verdict. Absence of proof is never read as proof of safety.

    d

    Zero-custody

    Read-only by design. No keys, no signing, no broadcasting on the hosted surface. It reviews; you execute.

    e

    Live on mainnet

    Running against Pharos Pacific Mainnet, chain 1672, with live Chainlink prices and on-chain code and allowance reads.

    One call before you sign.

    The loop is the same on every surface: resolve names from the registry, inspect the intent, inspect the exact bytes, then sign only what clears.

    Rec · 06The trust boundary

    What SafeHands never does.

    [X]

    Never holds a private key, and never signs or broadcasts on the hosted surface.

    [X]

    Never quotes a price it did not read live from Chainlink. A stale feed is reported, never guessed.

    [X]

    Never grants trust from anywhere but the registry's first-party evidence.

    [X]

    Never downgrades a BLOCK. Aggregation can only raise severity, never lower it.

    A verdict binds to exactly what was inspected. Act on different bytes, or after it expires, and the verdict no longer applies. The calling agent is solely responsible for honoring it.
